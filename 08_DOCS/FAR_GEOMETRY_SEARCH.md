# 较远数据库外构型探索

## 运行方法

在项目目录执行：

```powershell
C:\ProgramData\anaconda3\python.exe main.py --design-mode GENERATE_FAR
```

目标频率仍在 `00_USER_DESIGN/design_request.py` 的 `TARGET_FREQUENCY_HZ` 和
`GENERATIVE_ADDITIONAL_TARGETS_HZ` 中修改。也可以把 `DESIGN_MODE` 设为
`GENERATE_FAR` 后运行 `main.py`。该模式始终不提交 Abaqus，优先于验证开关。
原 `GENERATE` 局部搜索和 `RETRIEVAL` 检索继续保留。

## “远”的明确含义

九维参数逐维按当前数据库的最大值减最小值归一化，再计算欧氏距离：

`d(x,q) = sqrt(sum(((x_j-q_j)/(max_j-min_j))**2))`

候选必须满足到**整个训练数据库**的最近距离不低于 0.10。原局部生成限制
到锚点的距离不超过 0.035。新模式允许到搜索锚点距离最大 0.25，且同目标
候选两两距离至少 0.10。这是相对原局部微调更远的探索，不是全域远距离外推保证。
数据库发生变化后归一化尺度也会变化；本次尺度保存在运行清单中。

`FAR_SEARCH_POLICY` 可修改最小数据库距离、最大锚点距离和每目标候选数。
不要仅为凑够数量无限放宽不确定性门槛。阈值加大可能导致无候选。

## 算法和可信度限制

1. 使用数据库全部有效的24阶排序频谱寻找目标相关锚点。
2. 在锚点周围产生较大扰动，检查取值范围、固定15 mm阻尼的代数几何约束及全库距离。
3. 用独立缓存的实验频谱GPR进行多起点约束优化。优化中禁止回到数据库样本附近。
4. 预测目标误差不超过2%、预测标准差不超过目标频率12%的探索点，按不确定性及多样性筛选。
5. 输出实际几何参数与最近数据库样本的逐项差值。

12%的标准差门槛只是探索风险上限，不是频率精度保证。该GPR标准差未校准，不能当作
真实95%置信区间。实验训练有明确迭代预算，未替换原生产模型，也未证明优于原模型。
排序频谱逆序单独标记；即使没有逆序，也不代表物理模态身份已确认。
代数几何通过不等于网格、求解或真实目标频率通过。

## 查看结果

每次运行写入独立目录：

`07_RESULTS/inverse_design/frequency_9d/fixed_band_15mm/far_generated/<运行标识>/`

- `far_candidates.csv`：完整九维参数、固定15 mm阻尼、预测值及STD、到全库最近距离、风险标记。
- `nearest_geometry_differences.csv`：与最近数据库几何的逐参数对比，长度用mm、角度用度。
- `run_manifest.json`：数据指纹、归一化范围、搜索策略、各目标计数、训练警告。

所有候选都只是 `FAR_EXPLORATORY_REQUIRES_ABAQUS`，不能把预测接近目标称为设计成功。

## 后续真实验证（必须由用户显式开启）

建议首先每目标只选择1个低不确定性、无预测逆序且远离参数边界的候选，评估远距离策略，
不要直接批量验证全部点。使用已有批量入口，不需要另写Abaqus脚本：

1. 将 `DESIGN_MODE` 切回 `GENERATE`，否则远距离入口会继续只生成而不会验证。
2. 将完整 `far_candidates.csv` 路径填入 `BATCH_VALIDATION_CANDIDATE_CSV`。
3. 将所选ID填入 `BATCH_CANDIDATE_IDS`，关闭单个验证开关，显式开启批量验证开关。
4. 运行 `main.py`。这一步才会提交已有独立模态求解流程。

不改变几何链、材料、网格、边界或15 mm物理阻尼带宽。
以真实FE目标误差、指定排序阶次误差和几何距离分别评价；物理模态身份仍需振型证据。
若远点失败，应在该区域积累真实数据后评估模型，不把代理预测当成训练标签。
